The Core Thesis & Problem Statement

Large Language Models typically fail at rigorous investment and technical research because nothing forces them to commit. Given a raw research packet, naive one-shot prompts default to bland summaries littered with synthetic transitions ("delve", "testament to", "not only X but also Y"), cowardly hedging, hallucinated metrics, and zero falsifiable criteria.

Thesis Engine replaces naive prompts with a deterministic architectural pipeline: grounding atomic claims with verbatim string verification, stress-testing hypotheses via adversarial pre-mortems, synthesizing through Minto's Pyramid Principle, and enforcing a hard numerical traceability invariant.

🌐 Layer 0: Multi-Source Data Accumulation

Before analytical reasoning begins, Thesis Engine aggregates grounded primary source material across multiple specialized data channels, preventing stale cached assumptions and SEO hallucination.

Tavily Web Search API Primary Search

Direct API integration conducting live organic web crawling. Extracts high-density technical specifications, company filings, release notes, and real-time market data without consumer SEO clutter.

  • Parses clean markdown representations of retrieved articles
  • Preserves publication dates and original source URLs for claim attribution
  • Operates independently of LLM provider tokens
Gemini Google Search Grounding Temporal Anchoring

Native Google GenAI search tool integration (types.Tool(google_search=...)) with temporal anchoring instructions.

  • Injects explicit temporal qualifier (current_date) into prompt template
  • Prevents stale cached numbers for fast-moving metrics (headcount, pricing, funding)
  • Prioritizes primary disclosures (press releases, changelogs, live pricing)
Financial Modeling Prep (FMP) API Audited Financials

Fetches audited SEC 10-K / 10-Q statements and real-time equity fundamentals for company tickers.

  • Pulls Revenue, Gross Margin, Net Income, Operating Cash Flow, and EBITDA
  • Calculates valuation multiples: Enterprise Value (EV), P/E, EV/EBITDA, EV/Sales
  • Formats verified figures into deterministic Markdown tables before LLM ingestion
SerpApi / Google Scholar Citations Academic Literature

Synthesizes peer-reviewed scholarly literature for academic topics (e.g., LIIF, deep learning architectures).

  • Captures publication year, author teams, and citation count indicators
  • Extracts authoritative paper abstracts for objective empirical benchmarking
  • Ensures scientific rigor before synthesis begins

Curated Primary Dossiers & Zero Server Storage

To test the pipeline without hindsight bias, Thesis Engine includes anonymized SEC EDGAR filings (e.g. Datadog's August 2019 S-1 registration statement anonymized as Apex Systems). Every dossier uploaded or researched is processed purely in-memory: zero server storage, zero database persistence of user topics or documents.

🧠 Structured Reasoning Pipeline (Stages 1 to 3)

Standard LLMs jump straight from prompt to essay, causing compounding hallucinations and cowardly hedging. Thesis Engine breaks synthesis into three rigorously isolated reasoning stages with schema enforcement via Pydantic.

STAGE 1: Grounded Claim Extraction src/reasoning/claims.py

Deconstructs unstructured research dossiers into atomic assertions. Each claim is typed as FACT (audited or empirical metrics), ESTIMATE (forward projections), or OPINION (subjective commentary).

🔒 The Verbatim String Match Invariant (verify_claim_quotes):
Every claim requires a `source_quote`. The engine runs an exact substring match against the raw dossier. If an LLM fabricates or alters a single word in the quote, the claim is rejected immediately.
STAGE 2: 360° Candidate Theses & Adversarial Pre-Mortem src/reasoning/debate.py

Forces commitment by formulating 3 distinct, mutually opposing theses:

1. Bull Case

Aggressive compounding, multi-product expansion, customer lock-in.

2. Conditional Case

Margin-of-safety entry criteria, valuation discipline, inflection catalysts.

3. Bear / Pass Case

Structural friction, high concentration risk, decelerating net expansion.

⚔️ Adversarial Pre-Mortem Critic Agent (Du et al., 2023):
"Assume it is 3 years later and this investment lost 80% of value. Exactly how did it fail?" If all theses fail the pre-mortem, the arbitrator automatically issues an unvarnished PASS.
STAGE 3: Grounded Minto Synthesizer src/reasoning/minto.py

Constructs the draft using Barbara Minto's Pyramid Principle:

  1. Answer-First Conviction: Direct top-line investment recommendation and thesis statement. Zero throat-clearing warm-up.
  2. 3 Supporting Pillars: Mutually Exclusive, Collectively Exhaustive (MECE) arguments strictly citing verified Claim IDs ([C1], [C4]).
  3. Structural Risks & Catalysts: Failure mechanisms carried directly from the adversarial pre-mortem.
  4. What Would Change My Mind: Concrete falsification triggers strictly derived from cited metrics (e.g. Net Expansion falling below 120%), preventing subjective goalpost moving.

🛡️ Multi-Tier Guardrails & Voice De-Slopping Engine

Standard LLM apps rely on system prompts alone to maintain style and factual accuracy. Thesis Engine implements deterministic, non-negotiable code invariants that run locally after generation.

1. Hard Numerical Traceability Guard src/voice/traceability.py

Deterministic regex parser extracts every single number, percentage, dollar figure, and multiplier in the drafted memo.

✓ Verified Number Match

If a number maps back to an extracted GroundedClaim, it is marked as traceable and grounded.

✗ Zero Untraced Numbers Allowed

Any untraced or hallucinated figure fails validation immediately, preventing fabricated financial claims from slipping through.

2. Deterministic Anti-Slop Voice Linter src/voice/linter.py & banned_patterns.py

A deterministic local linter targeting Wikipedia AI-writing patterns, corporate consulting jargon, and investor cliches.

Banned Clichés

"delve", "testament to", "in an increasingly... world", "tapestry", "landscape", "holistic", "pivotal", "beacon", "poised to", "not only... but also".

Structural Tells

Em-dash clusters (≤ 1 per 750 words allowed), Rule-of-Three adjective triplets, passive hedging ("it's important to note").

Self-Refine Loop

If violations persist, src/voice/editor.py feeds the exact linter feedback back to the LLM to rewrite the draft until clean.

3. Category-Aware Recommendation Guardrail src/templates/guardrail.py

Maintains strict compliance and regulatory boundaries based on query classification:

For Topic / Industry / Macro

Strictly forbids investment advice phrases ("we recommend", "portfolio allocation", "target price"). Automated scrubbing cleanses policy leaks.

For Company Memos

Mandates decisive action: Buy, Conditional, or Pass. Hedging is penalized; conviction is enforced.

⚖️ Cross-Model Evaluation & Verification Harness (src/eval/)

Evaluating generative AI requires eliminating self-grading bias. Thesis Engine couples an un-rigged benchmark suite with an independent cross-model judge.

Cross-Model Independent Judge

Generator model and judge model are assigned independently (e.g. Claude 3.5 Sonnet judging Gemini 3.8 Flash, or vice versa) to prevent self-grading confirmation bias.

1. Thesis Clarity & Conviction 1 – 5
2. Falsifiability & Risk Realism 1 – 5
3. Evidence Grounding & Linkage 1 – 5
4. Prose Conviction & Slop Score 1 – 5
Symmetrical Mega-Prompt & Ablations

Contrasts the multi-stage pipeline against an identical, symmetric 2,000-token prompt receiving all instructions simultaneously.

  • Ablation Testing: Supports flags (--no-debate, --no-voice) to isolate the exact empirical lift provided by each stage.
  • Blind Evaluation: Generates anonymized review documents (blind_eval.md) for unbiased human audit.
  • Token & Cost Tracking: Real-time tracking of prompt tokens, completion tokens, and dollar costs across Gemini and Claude.
